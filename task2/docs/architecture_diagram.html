Tier 1

Public Entry & Load Balancing Tier

(Public Subnets: 10.0.1.0/24 & 10.0.2.0/24)
IGW: Attached

Application Load Balancer (ALB)

Cross-zone load balancer distributing public HTTP requests to backend targets.

Health Check: /api/health Timeout: 5s

Security Group: alb-sg

Accepts web traffic and initiates Security Group Chaining to backend.

Ingress: 80, 443 from 0.0.0.0/0 Egress: 5000 to app-sg

Restricted Forwarding: Port 5000 (Target Group)
Tier 2

Private Application Logic Tier

(Private Subnets: 10.0.10.0/24 & 10.0.20.0/24)
Zero Direct Public IP

StockPulse Compute (EC2 / Container)

Python 3.11 + Flask WSGI App running as unprivileged non-root user (appuser).

Port: 5000 RBAC Active IDOR Protected

Security Group: app-sg

Locked down: Ingress permitted ONLY from alb-sg on port 5000.

Ingress: 5000 from alb-sg Egress: 5432 to db-sg
▼
Secure Database Connection: Port 5432 (Internal VPC Only)
Tier 3

Isolated Database Storage Tier

(DB Subnets: 10.0.30.0/24 & 10.0.40.0/24)
NO INTERNET ROUTE (Isolated)

Amazon RDS PostgreSQL 15

Multi-AZ Subnet Group. Fully managed relational database for products & audit comments.

Public: FALSE Storage: KMS Encrypted

Security Group: db-sg

Zero internet reachability. Accepts connections strictly from app-sg on port 5432.

Ingress: 5432 from app-sg Egress: Deny All Outbound

Supporting AWS Management & Governance Services

AWS KMS

Hardware-level AES-256 encryption at rest for RDS and EBS volumes.

IAM Instance Profile

Least-privilege role: zero static credentials in code or containers.

SSM Parameter Store

Secure injection of database secrets and application tokens.

CloudWatch

Real-time health check alarms, target group metrics, and server logs.
